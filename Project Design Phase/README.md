# Project Design Phase

## Project Title
PocketSmart AI: Your Smart Budget & Recommendation Assistant

## System Design
PocketSmart AI is designed as a FastAPI web application.

## Main Components
- User Interface
- FastAPI Backend
- Budget Planning Logic
- Budget Recommendation System
- Static CSS Files
- HTML Templates

## Application Flow
1. User opens the application.
2. User selects the required budget planning category.
3. User provides the required budget details.
4. The application processes the input.
5. The system provides budget allocation recommendations.
6. The user can view the recommended budget.

## Technologies
- Python
- FastAPI
- HTML
- CSS
- Uvicorn
