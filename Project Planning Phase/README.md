# Project Planning Phase

## Project Title
PocketSmart AI: Your Smart Budget & Recommendation Assistant

## Project Plan

### Phase 1
Project idea and requirements were identified.

### Phase 2
The system design and application structure were planned.

### Phase 3
The FastAPI backend and web interface were developed.

### Phase 4
Budget planning and recommendation functionality were implemented.

### Phase 5
The application was tested for different budget planning categories.

### Phase 6
Project documentation and demonstration materials were prepared.

## Technologies Used
- Python
- FastAPI
- HTML
- CSS
- Uvicorn

## Final Goal
To develop a simple web application that helps users plan budgets and receive budget allocation recommendations.
