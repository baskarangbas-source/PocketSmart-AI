# Project Testing Phase

## Testing Objective

The objective of testing is to ensure that the PocketSmart AI application works correctly and provides the expected budget planning and recommendation features.

## Test Cases

### 1. User Interface Testing
- Check whether all pages load correctly.
- Check buttons, forms and navigation.

### 2. Login and Registration Testing
- Test valid user registration.
- Test valid login.
- Test invalid login details.

### 3. Budget Planning Testing
- Test Home Interior budget planning.
- Test Party Planning budget planning.
- Test Jewelry Planning budget planning.

### 4. Recommendation Testing
- Verify that suitable budget allocation recommendations are generated.
- Check the output for different budget inputs.

### 5. API Testing
- Verify FastAPI routes.
- Check API responses.
- Verify that the application runs without errors.

## Expected Result

The application should work correctly and provide suitable budget planning and recommendation results.
