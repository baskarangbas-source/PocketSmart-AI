# 💰 PocketSmart AI

## Smart Budget & Recommendation Assistant using Generative AI

PocketSmart AI is an AI-powered budget assistant that helps users manage their monthly income, expenses, and savings goals.

### Features
- Calculate remaining money
- Check savings goal feasibility
- Provide budget recommendations
- Suggest ways to reduce expenses
- Generate AI-powered savings suggestions

### Technologies Used
- Python
- Google Gemini API
- Google Colab
- Gradio
- GitHub
