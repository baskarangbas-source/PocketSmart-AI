# PocketSmart AI

Your Smart Budget & Recommendation Assistant.

## Features
- Home Interior budget planning
- Party Planning budget planning
- Jewelry Planning budget planning
- Simple budget allocation recommendations
- FastAPI web application

## Run locally

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Open `http://127.0.0.1:8000`.

## Render

Build Command:
```text
pip install -r requirements.txt
```

Start Command:
```text
uvicorn app:app --host 0.0.0.0 --port $PORT
```

This is an educational/demo implementation prepared for the PocketSmart AI project.
Do not commit API keys or passwords to GitHub.
